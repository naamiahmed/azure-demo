Azure Static Web Apps Demo

Learn how to deploy modern static websites using Azure Static Web Apps — fast, easy, and scalable hosting with GitHub integration.

What You’ll Learn

In this session, we’ll explore how to build and deploy a static website using HTML, CSS, and JavaScript — all hosted on Azure Static Web Apps. We’ll walk through the GitHub workflow, setting up the Azure resource, and understanding the benefits of serverless hosting. This is a hands-on beginner-friendly demo to help you get started with cloud web deployment.
